# Sensor Calibration

A collection of lab experiments on sensor measurement and calibration, including current and voltage calibration and experiments with temperature, gas, load, heart rate, and metal detection sensors.

## Experiments

| Experiment | Description |
| --- | --- |
| [Current Sensor Calibration](./current_sensor_calibration/) | Measure electrical current and calibrate the sensor readings. |
| Voltage Sensor Calibration | Measure voltage and calibrate the voltage readings. |
| [Temperature Sensor](./temperature-sensor/) | Read temperature measurements. |
| [Gas Sensor](./gas_senser/) | Read the output of a gas sensor. |
| [Load Cell](./load_cell/) | Take measurements with a load cell. |
| [Heart Rate Sensor](./heat_rate/) | Read heart rate measurements. |
| [Metal Sensor](./MEntal_senser/) | Test metal detection. |

## Repository Contents

The experiments are organized into separate folders, with Excel workbooks stored alongside them.
