# Sensor Calibration

A collection of lab exercises on sensor measurement and calibration. The project focuses on current and voltage calibration and also includes experiments with temperature sensors, gas sensors, and load cells.

## Experiments

| Experiment | What it covers |
| --- | --- |
| [Current Sensor Calibration](./current_sensor_calibration/) | Measuring electrical current and calibrating sensor readings. |
| Voltage Sensor Calibration | Measuring voltage and calibrating voltage readings. |
| [Temperature Sensor](./temperature-sensor/) | Reading temperature measurements. |
| [Gas Sensor](./gas_senser/) | Reading the output of a gas sensor. |
| [Load Cell](./load_cell/) | Taking measurements with a load cell. |

## Repository Contents

The experiments are organized into separate folders. The repository also includes Excel workbooks alongside the experiment folders.
